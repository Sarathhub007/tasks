# Git & GitHub Notes

## Git

Git is a version control system used to track changes in code.

Important Git commands:

- `git init` - Initialize a Git repository
- `git status` - Check the current state of the repository
- `git add` - Add changes to the staging area
- `git commit` - Save changes as a commit
- `git push` - Upload commits to GitHub
- `git pull` - Download the latest changes from GitHub
- `git clone` - Copy a GitHub repository to your computer
- `git branch` - Work with branches
- `git merge` - Combine changes from different branches

## GitHub

GitHub is a cloud platform where Git repositories can be stored and shared.

## GitHub Desktop

GitHub Desktop is a graphical interface for Git.

It allows developers to:

- See file changes
- Commit changes
- Push changes
- Pull changes
- Create and switch branches
- Resolve merge conflicts
- Work with GitHub repositories

## Merge Conflicts

A merge conflict happens when two branches contain conflicting changes and Git cannot automatically combine them.
